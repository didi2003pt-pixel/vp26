- monorepo npm workspaces;
- aplicação Next.js interna;
- pacote de autenticação;
- pacote de configuração tipada;
- pacote de base de dados Prisma;
- design system inicial;
- migração SQL versionada;

- autenticação com registo, login, verificação de email, sessão e RBAC;

- missões e prémios;

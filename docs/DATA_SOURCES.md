# Fontes de dados

- Número de barco: tabela Excel confirmada na auditoria Fase 0.
- Número de vela: certificado ANC/ORC mais recente fornecido.
- Nome público: registo operacional; nomes técnicos são aliases.
- Participação: matriz validada na Fase 0.
- Resultados: não incluídos no seed.

Os ficheiros `boats.json` e `stages.json` são derivados dos entregáveis da Fase 0 e não contêm nomes de tripulantes, telefones ou emails.

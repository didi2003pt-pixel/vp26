# FPV — Novo Website · Versão para Validação Interna

Referência visual e funcional consolidada para validação pela Federação Portuguesa de Vela antes do pedido de proposta técnica à Binary Brigade.

## Inclui
- Descobrir
- Competição
- Alto Rendimento
- Atletas e perfis
- Estrutura Técnica e Direção
- Formação (landing, arquivo e detalhe)
- Clubes (arquivo + perfil reutilizável)
- Notícias e artigo
- Federação
- Assembleia Geral
- Conselho de Arbitragem
- Centro de Documentação
- Projeto Olímpico LA 2028 e histórico
- Pesquisa global
- myFPV

Não substituir diretamente o WordPress em produção por estes ficheiros.
